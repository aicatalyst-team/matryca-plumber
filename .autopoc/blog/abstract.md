# Abstract

Matryca Plumber is an open-source, local-first AI daemon and MCP server for Logseq knowledge management. This proof-of-concept demonstrates deploying its Sovereign UI dashboard and FastAPI backend on OpenShift using UBI-based multi-stage container images. The PoC achieved a 100% test pass rate across health check, dashboard, preflight, and configuration API endpoints, validating that local-first AI tooling can run on enterprise container platforms without code changes.
